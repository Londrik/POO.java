#POO.java - Programação Orientada a Objetos

Este repositório foi desenvolvido com o objetivo de centralizar os estudos, resoluções de problemas e códigos práticos elaborados durante o aprendizado do paradigma de **Programação Orientada a Objetos (POO)** utilizando a linguagem Java.

A estrutura do projeto está dividida por blocos de evolução acadêmica (Unidades), cobrindo desde a transição da lógica estrutural básica até a manipulação de objetos e tratamento de dados complexos.

---

Conteúdo Teórico e Didático

    Se você busca entender o porquê de cada algoritmo ou a explicação dos conceitos que fundamentam os códigos, acesse o arquivo ExplicaçãoTécnica.md dentro da pasta da unidade correspondente.

Algoritmos de Destaque (Unidade 1)

    Criptografia Clássica (CifraDeCesar.java): Estudo focado na manipulação fina de cadeias de caracteres (String e char[]), utilização de operadores aritméticos de resto (%) para rotação do alfabeto e estruturas de repetição (for).

    Estruturação de Objetos (POO.java e POO2.java): Códigos iniciais demonstrando a criação de instâncias, escopos de variáveis e o comportamento de métodos na JVM.

Exercícios Práticos e Resolução de Problemas (Unidade 2)

    Bateria de Laboratórios (Atividade01.java a Atividade17.java): Esta sequência contém soluções focadas na captura de dados via console (java.util.Scanner), manipulação e validação de variáveis, tratamento de fluxos condicionais complexos (if/else, switch-case) e laços de repetição aplicados.

    Algoritmo de Tomada de Decisão (DesafiodasEleições.java): Aplicação prática simulando uma esteira de processamento de dados e contagem estatística com base em regras de negócio específicas.

Tecnologias e Padrões Utilizados

    Linguagem: Java (JDK 17 ou superior)

    Paradigma Principal: Orientado a Objetos (Classes, Objetos, Métodos e Encapsulamento)

    Convenção de Estilo: Padrão de codificação Java (Classes em PascalCase, métodos e variáveis em camelCase).
